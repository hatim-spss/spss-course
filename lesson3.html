Lesson 3: Cleaning data

Real data is messy. Before any analysis, you must check for mistakes, define missing values and prepare your variables.

What you will learn

  • How to define missing values
  • How to recode a variable
  • How to compute a new variable
  • How to find duplicate cases

Step 1: Look at your data first

  1. Click Analyze → Descriptive Statistics → Frequencies.
  2. Move your variables across and click OK.
  3. Look for impossible values, such as an age of 200 or a score of 999.

Step 2: Define missing values

Many surveys use a code like 99 for "no answer". SPSS must know this is not a real value.

  1. Go to Variable View.
  2. Click the Missing cell of your variable, then the small ... button.
  3. Choose Discrete missing values, type 99, and click OK.
Tip: Never delete a whole row just because one answer is missing. Mark it as missing instead.

Step 3: Recode a variable

Example: turn Score into groups (1 = Low, 2 = High).

  1. Click Transform → Recode into Different Variables.
  2. Move Score to the box, and type a new name such as Score_Group. Click Change.
  3. Click Old and New Values and enter your ranges, for example 0 to 69 becomes 1, and 70 to 100 becomes 2.
  4. Click Continue, then OK.
Tip: Always recode into a different variable. That way your original data stays safe.

Step 4: Compute a new variable

Example: the average of several questionnaire items.

  1. Click Transform → Compute Variable.
  2. In Target Variable, type the new name, for example Total_Score.
  3. In Numeric Expression, type a formula such as MEAN(Q1, Q2, Q3).
  4. Click OK.

Step 5: Find duplicate cases

  1. Click Data → Identify Duplicate Cases.
  2. Move the ID variable (for example Student) to the box.
  3. Click OK. SPSS adds a column marking duplicates.

Cleaning checklist

  • Checked every variable with Frequencies
  • Defined all missing values
  • Fixed or removed impossible values
  • Recoded into new variables, not the originals
  • Checked for duplicates
  • Saved a clean copy of the file

Practice

Use your Lesson 1 data. Create a variable called Pass where a score of 70 or more is 1 and anything lower is 0.
