Lesson 1: Entering data

In this lesson you will learn how to type your data into SPSS.

What you will learn

  • The difference between Data View and Variable View
  • How to name your variables
  • How to type in your data

Step 1: Open Variable View

Click the Variable View tab at the bottom left of SPSS. Each row here is one variable.

Step 2: Name your variables

  1. In the first row, type Student.
  2. In the second row, type Age.
  3. In the third row, type Score.
Tip: Variable names cannot contain spaces. Use Final_Score instead of Final Score.

Step 3: Enter the data

Switch to Data View and type the values below:

Student Age Score
12075
22282
32168

Practice

Add 3 more students of your own, then save the file with File → Save As.
