Lesson 7: Paired samples t-test

This test compares two measurements from the same people, for example a score before and after a training programme.

What you will learn

  • The difference between paired and independent tests
  • How to set up your data
  • How to run and read the test
  • How to write up the result

Paired or independent?

Situation Test
Same students, before and afterPaired samples t-test
Two different groups of studentsIndependent samples t-test

Step 1: Set up your data

Each student is one row, with two columns:

Student Pre_Score Post_Score
16068
25563
37074

Step 2: Run the test

  1. Click Analyze → Compare Means → Paired-Samples T Test.
  2. Move Pre_Score to Variable 1 and Post_Score to Variable 2 of Pair 1.
  3. Click OK.

Step 3: Read the output

SPSS gives you several tables. These matter most:

  • Paired Samples Statistics: the mean before and after.
  • Paired Samples Test: the mean difference, t, df and Sig. (2-tailed).
Pair Mean difference t df Sig. (2-tailed)

Example output with made-up numbers.

Tip: Newer SPSS versions show a one-sided and a two-sided p. Use the Two-Sided p unless you have a reason not to. If SPSS shows .000, report it as p < .001.

How to report it (APA style)

Scores increased significantly from before training (M = 61.5, SD = 8.2) to after training (M = 67.7, SD = 7.9), t(29) = -4.18, p < .001.

Assumption to check

The differences between the two scores should be roughly normal. Compute a new variable (Post_Score minus Pre_Score) and check it with Explore, as in Lesson 5.

Practice

Enter the three students above, then add 17 more of your own. Run the paired t-test. Did the scores change significantly?
