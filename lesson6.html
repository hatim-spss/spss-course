Lesson 6: Independent samples t-test

This test compares the average of a numeric variable between two separate groups, for example the scores of men and women.

What you will learn

  • When to use this test
  • How to run it in SPSS
  • How to read Levene's test and the t-test table
  • How to write up the result

Assumptions

  • One numeric outcome variable (for example Score)
  • One grouping variable with exactly two groups (for example Pass: 0 and 1)
  • Each person is in only one group
  • The outcome is roughly normal in each group (see Lesson 5)

Step 1: Run the test

  1. Click Analyze → Compare Means → Independent-Samples T Test.
  2. Move Score into Test Variable(s).
  3. Move your grouping variable into Grouping Variable.
  4. Click Define Groups, type the two codes (for example 0 and 1), then Continue.
  5. Click OK.

Step 2: Read Levene's test first

Levene's test checks whether the two groups have similar spread.

  • Sig. greater than .05: use the row Equal variances assumed.
  • Sig. less than .05: use the row Equal variances not assumed.

Step 3: Read the t-test row

Row Levene Sig. t df Sig. (2-tailed)
Equal variances assumed.412-2.3538.024

Example output with made-up numbers.

  • Sig. (2-tailed) less than .05: the two group means are significantly different.
  • Sig. (2-tailed) greater than .05: no significant difference.
  • Look at the Group Statistics table to see which group has the higher mean.
Tip: Only read the p-value from the row you chose using Levene's test. Ignore the other row.

How to report it (APA style)

Students who passed (M = 78.4, SD = 6.1) scored significantly higher than students who failed (M = 71.2, SD = 7.3), t(38) = -2.35, p = .024.

Tip: Report the means and standard deviations from the Group Statistics table, plus t, df and p.

Practice

You need more than 3 students for this test. Download the sample data in the coming Extras section, or add at least 20 students of your own, then compare Score between the two Pass groups.
